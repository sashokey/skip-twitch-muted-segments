Tampermonkey userscript that automatically skips red muted segments in Twitch video recordings. Adjacent muted segments are skipped together.

Install [Tampermonkey](https://www.tampermonkey.net/), open the [userscript](https://raw.githubusercontent.com/sashokey/skip-twitch-muted-segments/master/skip-twitch-muted-segments.user.js), and confirm installation. Reload Twitch and open a video recording. The script runs automatically without configuration.
